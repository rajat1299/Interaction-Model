# Prompt template v3

V3 leaves v2 and the v2 Wave-1 repair packet byte-for-byte reproducible. It only makes explicit
that consumption persists while its executed action or matching disposition remains visible; a
later inert snapshot or retained source text does not reverse that state. The three-request
follow-up is separate v3 evidence; it reuses the approved owner authorization, and its planner
itself performs no provider call.

The v3 packet binds its renderer request identity and each runtime `session_start.prompt_hash` to
this prompt. It retains one original post-schedule `idle(no_trigger)` prefix as a regression control;
the two new targets are only the retained-response and handled-timer tails that failed under v2.
